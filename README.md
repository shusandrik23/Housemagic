# Чистый Лист (CleanPage)

Геймифицированный семейный трекер уборки в стиле школьной тетради в клетку:
записи синей, красной и зелёной ручкой, питомец-компаньон, 20-минутные зоны,
фото «До/После» и монеты-пуговицы.

**Стек:** Flutter (Android, iOS, Web), Firebase Auth (Google), Cloud Firestore,
Cloud Storage, `provider`.

> Аккаунт и семья **общие с YouBoost** (репозиторий Poleznieprivichki): один
> Firebase-проект `poleznie-privichki`. Подробности в
> [docs/YOUBOOST_INTEGRATION.md](docs/YOUBOOST_INTEGRATION.md).

## Возможности

### Модуль A: вход
- **Вход через Google:** `FirebaseAuth` + `google_sign_in` 7.x, на вебе
  `signInWithPopup`. Повторный вход автоматический: сессию хранит FirebaseAuth.
- **Вход по коду.** Код можно ввести на экране входа. Код взрослого
  обрабатывается сразу после входа через Google. Код ребёнка позволяет войти
  без Google, через анонимную сессию на детском телефоне.
- **Первый вход.** Создаётся профиль `users/{uid}`, затем пользователь выбирает
  «Создать новый Дом» (онбординг: комнаты, модификаторы, питомец, PIN) или
  «Присоединиться к Дому». Если семья уже есть, сразу открывается разворот
  «Сегодня».

### Модуль B: дети
- **«+ Добавить ребёнка»** на вкладке «Семья и Домик»: имя, возрастная группа
  (`4-6`, `7-10`, `11+`; таймер 5, 10 или 15 минут), питомец-напарник. Защита —
  Родительский PIN-код дома, его SHA-256 с солью хранится в
  `households/{fid}.parentPinHash`.
- **Переключатель профиля** в шапке открывает «Академию Юных Хранителей»:
  крупные кнопки, монстрики («Носочный Гоблин», «Крошко-Жук» и другие), таймер,
  кнопка «Отправить фото-отчёт родителям», Банк желаний. Выйти можно только по
  PIN-коду или биометрии. Детский режим сохраняется при перезапуске приложения.
- **«Привязать телефон ребёнка»** выдаёт код. На телефоне ребёнка его можно
  ввести после входа через Google или анонимно. Весь прогресс сохраняется.
- **Проверка квестов.** Квест с фото «После» получает статус
  `pending_approval`, у родителя появляется стикер «Проверить квест ребёнка».
  Кнопка «Принять ✨» ставит статус `completed`, начисляет золотые пуговицы,
  продлевает серию и добавляет фото в Альбом Побед. Кнопка «Переделать»
  возвращает квест с комментарием.

### Модуль C: покупки
- **Две вкладки-закладки:** «🥕 Продукты» (`grocery`) и «🧽 Для дома и уборки»
  (`household_supplies`).
- **Быстрая запись строкой** («Молоко 2 л» разбирается на название и
  количество). Отдел определяется автоматически, его можно выбрать вручную.
  Товары группируются по отделам магазина.
- **Кнопка «Закончилось средство / Нужны материалы»** есть в карточке
  20-минутной зоны и в карточке «Ремонт по дому». Она добавляет позиции
  **только** во вкладку `household_supplies`, без дублей. Подсказки зависят от
  модификаторов дома (кошка, собака, робот-пылесос, посудомойка).
- **Синхронизация в реальном времени** через Firestore snapshots.
- **«Завершить поход в магазин»** переносит купленное в `shopping_trips` и
  начисляет +25 пуговиц, а за 10 и больше позиций +40. В детском режиме
  награда идёт ребёнку.

## Структура

```
lib/
  core/          тема-тетрадь, коды и PIN, логика покупок, возраст, серия
  models/        Household, Member, ChildProfile, ChildQuest, ShoppingItem…
  repositories/  Firestore: дом/семья, дети, квесты, покупки, коды
  services/      Google-вход, фото (Storage), биометрия
  state/         SessionController — сессия, дом, детский режим
  screens/       вход, онбординг, Сегодня, Покупки, Семья, Детский режим
  widgets/       лист в клетку, стикеры, PIN-клавиатура, пикер средств
firebase/        правила Firestore (фрагмент для общего проекта) и Storage
test/            логика, репозитории (fake_cloud_firestore), сценарии UI
```

## Запуск

```bash
flutter pub get
flutter test
flutter run -d chrome          # веб работает сразу с конфигом проекта poleznie-privichki
```

Для Android и iOS:

```bash
dart pub global activate flutterfire_cli
flutterfire configure --project=poleznie-privichki   # перезапишет lib/firebase_options.dart
flutter run --dart-define=GOOGLE_SERVER_CLIENT_ID=<Web client ID из Google Cloud>
```

Остальная настройка Firebase (правила, Storage, SHA-ключи) описана в
[docs/YOUBOOST_INTEGRATION.md](docs/YOUBOOST_INTEGRATION.md#что-сделать-в-firebase).
